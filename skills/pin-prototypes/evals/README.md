# Evaluation fixtures

`evals.json` names three prompts, the fixture under `fixtures/` each runs against, and what to check. They document what the Draft, Run, and Review phases are for: a complete prompt set from a brief, with the push-back table written before any output exists; a standing header distilled from output rather than from the prompt; and a review note that takes behaviour from the brief and layout from the prototype. Run by hand with `skill-creator` before a merge that changes `SKILL.md`, and record the outcome in the pull request.
