# Evaluation fixtures

`evals.json` names two prompts, the fixture under `fixtures/` each runs against, and what to check. They document what the Draft and Run phases are for: a complete prompt set from a brief, with the push-back table written before any output exists, and a standing header distilled from output rather than from the prompt. Run by hand with `skill-creator` before a merge that changes `SKILL.md`, and record the outcome in the pull request.
