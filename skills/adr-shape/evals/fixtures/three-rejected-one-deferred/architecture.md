# Architecture

## Entries

An entry is a dated piece of writing with metadata. Where and how entries are stored is open item 2.

## Open, in the order they block work

1. **Sync between devices** — inherits ADR 0003's requirement that entries stay readable without the app; the format decided in item 2 constrains it.
2. **On-disk format for entries** — inherits ADR 0003's requirement that entries stay readable without the app.
3. **Export to PDF** — inherits nothing yet.
